# 提示音文件（③）

把音频文件放这里，文件名固定（前端按名加载，缺文件时静默不报错）：

- `block.mp3`     —— 拦截/下单被拒时播放
- `submit.mp3`    —— Alpaca 确认订单成交时播放（买入、加仓、减仓、平仓统一）
- `stop_lose.mp3` —— 自动止损触发、普通挂单超时自动撤单
- `cancel.mp3`    —— 手动撤单获得券商终态确认
- `ui_scoll.mp3`  —— 买入/卖出/加仓数量及目标收益用鼠标滚轮实际改变数值时播放
- `wall.mp3`     —— GEX 破墙提醒（涨破 call wall / 跌破 put wall）

`buy.mp3`、`sell.mp3` 目前保留在目录中，但前端不再加载：主动点击或券商仅受理订单时保持静音。

说明：
- 由设置页「提示音」开关（`state.sound`）统一门控。
- 浏览器自动播放策略要求先有用户交互，页面加载后首次点击/按键后才会出声（正常操盘即满足）。
- 止损抢占中的“撤止盈”不重复播放；自动平仓成交也不再重复播放普通成交音。
- 格式用 mp3（兼容性最好）；非滚轮音量为 0.5，滚轮音量为 0.32。
- 加载路径：`/static/sounds/<name>`，扩展名以 `SFX_FILES` 里写的为准
  （见 `static/app.js` 的 `initSfx`/`playSfx`）。
- 破墙提醒音 2026-08-29 换成 `wall.mp3`；上一版是 2026-08-21 从 `static/watcher/alert.wav`
  复制来的 `gex_wall.wav`，文件仍留在目录里但前端已不加载。
  **觉得不合适直接换掉同名文件即可**，前端不认内容只认文件名。
- 破墙提醒除受本目录的「提示音」总开关门控外，设置页还有一个单独开关
  （`GEX 破墙提醒`），盘中嫌吵可以只关它、不影响成交/拦截音。
